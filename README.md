# موقع APTIQ

موقع ثابت (HTML + CSS + JavaScript) من 3 صفحات، عربي RTL، متجاوب مع الكمبيوتر والتابلت والموبايل.

## الملفات
- `index.html` — الرئيسية: الهيرو، الخدمات، لماذا APTIQ، منهجية العمل، فورم التواصل.
- `about.html` — من نحن: فلسفتنا، قيمنا، معايير الجودة.
- `services.html` — الخدمات السبعة بالتفصيل، ولكل خدمة رابط مباشر (مثل `services.html#ppf`).
- `assets/css/style.css` — كل التنسيقات.
- `assets/js/main.js` — قائمة الموبايل، وفورم الحجز.
- `assets/img/` — اللوجو، الشكل السداسي، أيقونات المتصفح، وصورة المشاركة على السوشيال.
- `sitemap.xml` و `robots.txt` و `site.webmanifest` — لمحركات البحث.

## قبل النشر
1. **الدومين:** استبدل `https://aptiq.com` بالدومين الحقيقي في الصفحات الثلاث و`sitemap.xml` و`robots.txt`.
2. **بيانات التواصل:** استبدل كل ما بين أقواس مربعة مثل `[رقم الجوال]` و`[البريد الإلكتروني]` و`[أيام وساعات العمل]`.
3. **روابط السوشيال:** ضع روابط الحسابات مكان `href="#"`.
4. **الصور:** كل مربع رمادي مكتوب عليه image له تعليق فوقه فيه كود `<img>` جاهز. احفظ الصورة بصيغة WebP في `assets/img/` واستبدل المربع بالكود.

## الفورم
- العميل يقدر يختار أكثر من خدمة، والفرع من قائمة منسدلة.
- الفورم جاهز للعمل على **Netlify** بدون أي إعداد: الطلبات تظهر في لوحة Netlify تحت Forms.
- لو هتستخدم خدمة تانية (Formspree مثلًا) ضع رابطها في `data-endpoint="..."` على وسم `<form>`.

## النشر
ارفع محتوى المجلد كما هو على Netlify أو GitHub Pages أو أي استضافة. مجلد `_build` غير مطلوب على السيرفر.
